# Sky panorama source

`sky2.jpg`, `sky5.jpg`, `sky13.jpg`, and `sky15.jpg` are the equirectangular
versions of their corresponding skies from
[Philo's Sky Collection](https://www.philohome.com/skycollec/skycollec.htm).
The collection's author states that its skies may be used for any purpose,
The app deterministically selects one of these four panoramas from the active cloud seed.

The source image is a 2800 × 1400 JPEG panorama. I use it as the texture for the background skybox representing the cirrus cloud layer.
